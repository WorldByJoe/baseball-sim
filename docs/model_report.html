Run 7 Model Report

What the model review's three phases did when measured in full games, where the model still disagrees with the league, the likeliest reasons, and whether more work is worth it. 15 October 2026. The game-by-game notes are now on the playoffs page, under each game.

Summary

Run 7 fixed the league's run total and made the game forecasts slightly worse. The engine now scores the right number of runs when the new fielding meets last week's players (4.43 a game against the league's 4.43), and its double plays and infield hits match the league's. But the same fielding change cost game-level skill: on the same 985 games, every version with the new fielding forecast worse than the same version with the old, by 0.003 to 0.007 in Brier score, two to three standard errors. The refitted hitters, walks and the other phase-2 changes were neutral.

A harness bug turned up along the way. The replay script built each pitcher once per game and reused him in every replay, so anything drawn at random for him never averaged out. It explained a little of run 7's loss (Brier 0.0020 back, not significant) and is fixed on engine-dev. The live playoff engine still has it.

The model is at diminishing returns for forecasting. Team-level skill has not moved since run 4 (a team-strength error near 5.5 wins a season), and game-level skill peaked at run 6. The 2025 season, never seen by the model, repeated every part of this. Run 7's fits with the old fielding (run 7.5) then proved the best forecaster of every version in both seasons.

What run 7 did

Run 7 replayed the 2026 season out of sample, 400 times a game, with three phases of changes. Phase 1 changed the field: infielders dive and must get up, base covers arrive in time, and real fielders and catchers carry their own Savant range and framing. Phase 2 changed the fits: walks net of intentional walks, timing precision measured directly from contact depth, three unidentifiable traits held fixed, and call-ups given a lower prior. Phase 3 added each pitcher's uncertainty and a scoring protocol that removes replay noise.

The part of the new fielding that hurts is the base covers. The old fielding with only the code review's bugs fixed (the pitcher covering first and the man covering second arriving in time, the going runner, the wild throw) forecast as badly as the whole new fielding: 0.0044 worse than run 6 on fold A. Building each replay's pitchers afresh, so his randomly drawn fielding traits average out, recovered only 0.001-0.002. Plays that now come out right, 3-1 putouts and double plays, cost forecast skill, and the reason is not found. A later test (below) showed this cost is about the size of refitting noise, so it is not established. The live playoff engine keeps its old covers anyway, and the TV's Ballgame uses the new fielding, where matching the league's box scores matters more than forecasting.

The realism changes and what they taught (15 October)

Four of the report's suggestions were built and fitted. Each made the league's statistics more realistic, and none was adopted for the live forecasts. They now run in the TV's Ballgame (engine v3.10, fielding v1.19), where box scores that look like the league's matter most.

The general lesson: differences between separately fitted versions are mostly refitting noise. Each version refits every player through the simulator, and that fit carries its own simulation noise. Run 7.5 was refitted with nothing changed but the emulator's random seeds:

The pure refit scored 0.0070 worse (se 0.0019), worse even than the topped-ball engine. The paired bootstrap treats the player fits as fixed, so it hides a source of variance about as large as every effect this review measured. Run 7.5 was also chosen as the best of about ten noisy versions, so part of its lead is luck, the winner's curse that Cawley and Talbot (2010) showed can match the real differences between methods. Averaging two fits did not help: the refit's errors were a consistent, different estimate of who is good.

Realism and forecasting can still genuinely diverge, and the literature names why. Fitted models hide compensating errors that a fixed process exposes (Hourdin et al. 2017). A model that explains well need not predict well (Shmueli 2010). Matching league averages is calibration, while forecasting a game needs sharp differences between two teams (Gneiting, Balabdaoui and Raftery 2007). These are real, but in this study they were smaller than the refit noise.

What follows for any future change: judge it against at least three refits of the unchanged model, and treat a forecast difference under about 0.007 Brier between separately fitted versions as unproven. Forecast skill comes from more precise player estimates, not league mechanics. Realism goals belong to the TV game; forecast goals belong to the live pages.

Where the model disagrees with the league, most concerning first

Every number below is engine against real, from run 7's audit of 985 second-half games (four replays each, the league's 2026 Statcast for the real side). Concern weighs three things: how much the error moves runs or forecasts, how sure we are it is the model's fault, and how much it matters to the model's purpose.

  1. HighThe new fielding cost game-forecast skill. Brier rose 0.003 to 0.007 wherever it went in, and the forecasts spread wider while picking fewer winners (share sd 0.086 to 0.096; favourite won 61% to 56-58% on fold A). This ranks first because forecasting games is what the model is for, and because the change that caused it fixed the league totals. A model can now match the league's averages and still forecast worse. The size is small, about a fifth of the gap between the model and a coin flip, but it is consistent.
  2. HighBalls in play turn into too many runs. Runs ran 4.63 a game against 4.43 once the players were refitted. The audit splits the excess two ways. Contact quality is worth 0.14 runs a game: the engine's contact, given real outcomes, is worth 0.046 runs a ball against the real 0.041. Conversion is worth 0.30: the same engine contact, given the engine's own outcomes, is worth 0.057. Conversion is the larger part, and it is fielding, baserunning and carry, not swings.
  3. HighToo many extra-base hits on every kind of ball. Doubles ran 0.054 a plate appearance against 0.040, a third too many, in every run since the audit began. Line drives fall for hits at the league's rate (0.639 against 0.634) but go for extra bases 26% of the time against 20%. Grounders go for extra bases 4.1% against 2.5%, and fly balls 7.5% against 5.7%. The extra doubles are worth about 0.14 runs a game. The excess sits in how far a hit goes, not whether it falls.
  4. HighGround balls still fall for hits too often with real players. On real fitted players, grounders became hits 30.6% of the time against the league's 26.8%. On the engine's own model teams, the same fielding matches the league exit-speed band by exit-speed band. The excess therefore comes from the mix of grounders real players hit in the engine, harder than the league's, not from the fielders.
  5. MediumThe shape of contact is wrong at both ends. Balls hit at 105 mph or more were 9.8% of balls in play against 7.8%, and 100-105 mph balls 12.4% against 14.2%. Weakly topped balls (under 70 mph, below −10 degrees) were 2.5% against 5.5%, half the league's. Fly balls at 25-50 degrees were 25.2% against 21.6%, and grounders 42.8% against 45.5%. Three rounds of tests (collision geometry, friction, the scatter's shape) left the launch-angle part unchanged.
  6. MediumTeam forecasts have stopped improving. The team-strength error has sat near 0.034 of win rate (5.5 wins a season) since run 4, whatever changed underneath. In the first half the model's correlation with real wins (0.36) is well below the second half's own record (0.65). In that half the model adds almost nothing beyond the record. Pooled over halves the model is reasonable, but none of tonight's mechanisms moved it.
  7. MediumLong fly balls carry too short and liners too long. At 100-105 mph and 20-35 degrees the engine's home-run share was 0.10, 0.42 and 0.55 where the league's was 0.19, 0.55 and 0.64. Liners at 15-20 degrees landed 10-20 ft long, even counting only balls not caught, so Statcast's catch-point distance explains little of it. These partly offset each other and partly feed the doubles excess.
  8. LowRunners take too few extra bases. First to third on a single ran 24.9% against 31.3%, scoring on a fly ball with a man on third 55.1% against 61.7%, and double plays 36.4% against 41.2% on real players. The run effects are small and partly cancel the doubles excess. The send margins were fitted before the new fielding and were not refitted.
  9. LowThe home edge in strikeouts is now too large. Home hitters struck out 1.6 points less often than visitors in the engine against 1.1 points in the league, and their hit edge was smaller (+0.0065 a plate appearance against +0.0086). The eye setting was fitted on run 5's hitters and drifted when they were refitted.
  10. LowSome hitter traits still cannot be measured. Timing precision is now pinned down by contact depth (its uncertainty fell 38%), but face scatter barely moved with its new measure, and learning, coverage and commitment remain prior plus noise. They are held at their means, which costs little.

Likely mechanisms, most likely first

  1. The engine lacks a population of mishit balls. Real hitters top, jam and nub a steady share of balls, and those weak grounders are easy outs. The engine makes half as many, so its grounders arrive harder and more of them get through, while its fielders handle each exit speed as the league's do. This one gap explains the ground-ball hit excess (failure 4), the missing weak contact and the surplus of 105-mph balls (failure 5), and part of the run excess (failure 2). Evidence: grounder hit rates match band by band on model teams but not overall on real players; weak topped balls run at half the league's rate. A mishit population can be measured directly from Statcast's squared-up rate and exit-speed distribution, so it would be a measured mechanism, not a tuned one.
  2. The batter-runner takes second too easily. Line drives fall at the right rate but become doubles too often, and the same holds on grounders and flies. The batter's decision to stretch a hit depends on the throw beating him by a margin, and on the outfielder's time to stop, turn and throw. Meanwhile runners already on base are sent too rarely. The two decisions use separate margins, fitted at different times, so one is likely too bold and the other too cautious. Evidence: failures 3 and 8 together, with the hit rate itself correct.
  3. Outfielders stand in generic spots. They start at the league's average depth and shading for the batter's side, not for the hitter's power and spray. Real outfielders play deep for sluggers and shade pull hitters, which takes away gap doubles. Together with liners carrying long (failure 7), this sends more hits into the gaps and to the wall. Evidence: the extra-base excess is largest on line drives, the balls positioning matters most for.
  4. The new fielding magnifies differences between games that do not decide them. Something in dives, recovery and base covers moves each game's forecast by about two points of win share in directions unrelated to who won. It is not infielders' or outfielders' speed (correlations 0.06 and 0.09 with each game's change) or the lineups' ground-ball mix (0.02). A likelier route is that the new range rewards particular hitter or pitcher profiles, such as hard-hit grounders or pull rates, more than real fielding does. This is the least understood failure and the most costly one.
  5. Outcome-fitted constants drift when the mechanisms under them change. The drag and spin-keep settings, the send margins and the home edge's eye were each fitted to outcomes, then left in place while other parts changed. Each now carries a small misfit: carry, sends, the home strikeout edge. This is Joe's weak-tuning rule seen from the other side, and it predicts that every mechanistic fix will need a short refit of the surrogates downstream.
  6. Launch angle depends on something not yet modelled. The fly-ball excess survived the collision geometry, force-dependent friction, a seven-setting swing refit and two scatter shapes. Candidates left are the pitch-height miss, the read of breaking balls, and the coupling between a hitter's aim and his attack angle. None has direct evidence yet.
  7. Team strength is limited by what traits can know. The other half's record beats the model in the first half because it carries team-level information the traits do not: bullpen usage, managing, health, the coaching term found earlier (+0.07 correlation in sample). The model's team error is close to what a calibrated forecast of its skill should show, so no engine mechanism will move it much.

Assessment

For forecasting, the model is at diminishing returns. Three facts say so. The team-strength error has not moved since run 4, through four rounds of engine changes, in either season. Game-level changes between versions are now a few thousandths of Brier, about half the model's whole edge over the home team's season rate, and they go both ways. And the largest single improvement to the league's statistics in this review, the new fielding, made the game forecasts worse. Matching league averages and forecasting games have stopped pulling in the same direction.

What remains worth trying, in order:

  1. Run 7.5: run 7's fits with the old fielding. Confirmed on both full seasons (above): run 6's game skill and the best team forecasts yet. It is the forecasting engine to adopt for the live pages and for next year.
  2. Fix the pitcher cache in the live engine. Done 15 October, with the other known bugs except the base covers.
  3. Find what in the new fielding hurts, then keep the rest. Tried 15 October: no part was significant once refit noise was counted (see the realism section). Its base covers and double plays are clearly right. Splitting it into dives, recovery and covers, one at a time on fold A, would take an evening and might give the league's statistics without the forecast cost.
  4. Give hitters a mishit population. Built 15 October as the topped ball; in the TV game. It is the most likely single cause of three failures (grounder hits, weak contact, excess hard contact) and can be fitted to measured Statcast quantities. It is worth doing for the model's believability more than its forecasts.
  5. Unify the runners' send decisions and let outfielders play hitters. The send rule was built 15 October and is in the TV game; positioning was not built. One margin rule for the batter and the runners, and outfield depth and shading by the hitter's measured spray and power, should take most of the doubles excess. Again, more believable, not much more predictive.

What is not worth more effort: the launch-angle shape (three tests, no lever found), the ball's physics (already at what the lab can resolve), and the past Octobers as a test (too few games). For a recreational model, a sensible stopping point is run 7.5 plus the live fix. After that, effort is better spent on what the model is fun for, such as the game notes, the couch analyst and the wall, than on another hundredth of a win.
